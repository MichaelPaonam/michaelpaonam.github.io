# michaelpaonam.com

Personal portfolio and technical blog. Built with Jekyll and deployed to GitHub Pages.

## Local Development

```bash
cd docs
bundle install
bundle exec jekyll serve
```

Site will be available at http://localhost:4000.

## Structure

The site source lives in the `docs/` directory (GitHub Pages publishes from there). Uses the Minima theme with a custom three-column layout.

## Writing Posts

Add new posts to `docs/_posts/` with the naming convention `YYYY-MM-DD-title.md`.
